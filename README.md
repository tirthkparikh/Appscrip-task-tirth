# Appscrip-task-tirth

A product listing page (PLP) demo built with Next.js.

## Features

- Server Side Rendering (SSR)
- Responsive design for mobile/tablet
- SEO optimized with meta tags & JSON-LD
- Mock product data via FakeStoreAPI

## Tech Stack

- React + Next.js
- Tailwind CSS
- Deployed on Netlify
